App auf Smartphone installieren

1. Direkt über den Handy-Browser (Empfohlen, ohne Datei)

Die Web-App ist als Progressive Web App (PWA) vorbereitet. Du kannst sie ohne App Store direkt auf deinem Startbildschirm ablegen:

  • Android (Chrome / Edge / Firefox): Öffne die Seite, tippe oben rechts auf das Menü (3 Punkte) und wähle "App installieren" oder "Zum Startbildschirm hinzufügen".
  • iPhone / iPad (Safari): Öffne die Seite in Safari, tippe unten auf das Teilen-Symbol (Viereck mit Pfeil nach oben) und wähle "Zum Home-Bildschirm".

Die App startet danach wie eine normale App im Vollbild mit eigenem PB-Icon.

2. Als echte .APK-Installationsdatei (Android)

Wenn du eine echte .apk-Datei zum Weitergeben oder Installieren benötigst:

  1. Lade den Projektordner auf einen Webspace hoch (z. B. via GitHub Pages oder Vercel).
  2. Gehe auf PWABuilder.com (kostenloses Microsoft Tool).
  3. Gib deine Webadresse ein und klicke auf "Package for Android".
  4. Du erhältst sofort eine fertige .apk-Datei, die du direkt auf dem Android-Handy anklicken und installieren kannst.
